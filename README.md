# Family-Dental-Care
<p>A modern, responsive front-end website for Family Dental Care, a family-focused dental clinic. The website provides visitors with information about the clinic, dental services, doctors, contact details, and appointment options through a clean and user-friendly interface.</p><br>
<h1>Features</h1>
<ul>
  <li>Responsive design for desktop, tablet, and mobile devices</li>
  <li>Modern and professional dental clinic interface</li>
  <li>Home/hero section</li>
  <li>About Family Dental Care section</li>
  <li>Dental services section</li>
  <li>Doctors/team section</li>
  <li>Appointment/contact section</li>
  <li>Smooth navigation between sections</li>
</ul>
<br>
<h2>Technologies Used</h2>
<ul>
  <li><b>HTML5</b></li>
   <li><b>CSS</b></li>
   <li><b>JavaScript</b></li>
</ul>
